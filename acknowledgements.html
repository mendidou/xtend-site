Built on the shoulders of giants.

Xtend uses the following open-source projects. Thank you to their authors and contributors.

WebRTC
BSD 3-Clause
Google's WebRTC implementation, packaged as a Swift Package by stasel. Powers the iPhone ↔ Mac peer connection (DTLS-SRTP media, SCTP data channels).
SwiftTerm
MIT License
Terminal emulator by Miguel de Icaza — renders the terminal on iOS and drives the Mac-side PTY relay.
swift-argument-parser
Apache 2.0
Apple's argument-parsing framework, used by build-tooling helpers inside the project.
Sparkle
MIT License
Software-update framework for macOS — keeps the Mac companion up to date.
Firebase (Crashlytics, Remote Config)
Apache 2.0
Crash reporting and server-side configuration. Never your code or terminal contents, and switched off entirely by the Share Usage Data toggle — see the privacy policy.
Mixpanel Swift
Apache 2.0
Usage counters, opt out via Share Usage Data on the iPhone or the Mac — see the privacy policy.
jose
MIT License
JWT / JWS implementation used server-side to sign Xtend session tokens and verify Apple ID tokens during Sign-in-with-Apple flow.
ws
MIT License
Node.js WebSocket server used by our signaling backend to shuttle WebRTC handshake messages between the iPhone and the Mac.
IBM Plex Mono
SIL Open Font License 1.1
Monospace typeface used on this website and in the app's terminal and labels.
